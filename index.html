What you get

Everything in one launcher

Pick a world, press Play

Every instance is a card with its own version and loader. Choose one, press the big orange button, and you're in — about 6 seconds after the first launch, because game files download in the background while you browse.

  • Vanilla, Fabric, Forge, NeoForge and Quilt on any version
  • Uses your real .minecraft folder, or a private one per instance
  • Java is found or downloaded for you

Mods without the hassle

Search Modrinth from inside the launcher and install mods, resource packs, shaders and modpacks. Required dependencies come along automatically.

  • ⚡ Performance pack — Sodium, Lithium, FerriteCore and more in one click
  • Turn any mod on or off, or delete a few at once
  • Warns you when a mod doesn't match your loader

Skins from NameMC, in one click

Browse trending NameMC skins in a launcher window, preview any of them in 3D, and press Use or Save. Or paste a username to copy that player's skin.

  • Drag-to-rotate 3D preview with classic and slim arms
  • A skin library you can switch between anytime
  • Offline accounts start as Steve

Find a server in seconds

Online and Cracked tabs list recommended servers first, then every server of that type from a public directory — with live player counts, ping and a search bar. One click joins.

  • Warns you before joining a premium server with an offline account
  • Save your own servers and pick which instance joins them

Questions

Is Alaska Launcher made by Mojang or Microsoft?

No. It's an independent launcher. Minecraft game files are downloaded directly from Mojang's servers, and you sign in on Microsoft's own page — the launcher never sees your password.

Do I need to own Minecraft?

To play on online (premium) servers and Realms, yes — sign in with the Microsoft account that owns Minecraft: Java Edition. Offline accounts work for singleplayer, LAN and servers that allow them.

Why does Windows warn me when I run it?

The installer isn't code-signed yet, so Windows SmartScreen doesn't know it. Click More info → Run anyway. You can check the file against the SHA-256 checksum above.

Will it touch my existing .minecraft folder?

By default instances use your normal .minecraft folder, so your worlds and resource packs are right there. Any instance can use its own private folder instead, and deleting an instance never deletes your .minecraft.

Does it collect any data?

No. There are no ads, analytics or telemetry. Accounts, settings and files stay on your computer.

Is there a macOS or Linux version?

Not yet — the current release is for Windows 10 and 11 (64-bit).
