# Alaska Launcher

A fast, clean Minecraft: Java Edition launcher for Windows.

**[⬇ Download the latest version](https://github.com/ahmad64654/AlaskaLauncher/releases/latest)**

## Features

- **Accounts:** Microsoft sign-in, or offline accounts (any 3–16 character username).
- **Every version and loader:** Vanilla, Fabric, Forge, NeoForge and Quilt. Uses your real `.minecraft` folder by default, or a private folder per instance.
- **Mods page:**
  - Search and install mods, resource packs, shaders and modpacks from Modrinth.
  - Enable, disable or delete anything you've installed.
  - One-click ⚡ performance pack: Sodium, Lithium, FerriteCore and more.
- **Skins:**
  - 3D preview, upload a PNG, or copy any player's skin.
  - Browse NameMC skins and press **Use** or **Save**.
  - Steve is the default skin for offline accounts.
- **Servers:** Online and Cracked tabs with recommended servers first, every server from a public directory, live ping, search and one-click join.
- **Fast:** game files download in the background; launches after the first one take about 6 s to get in-game.
- **Smooth:** tuned Java settings and higher game priority.
- **Game console:** its own window, with live logs, color-coded errors and crash details.
- **Extras:** world backups, screenshot gallery, export as `.zip` or `.mrpack`, tray quick-play, keyboard shortcuts.
- **4 themes:** Tundra (default), Aurora, Glacier and Midnight Sun.
- **Private:** no analytics, telemetry or ads. Your data stays on your computer.

## Install

1. Download **`AlaskaLauncher-Setup-x.y.z.exe`** from the [latest release](https://github.com/ahmad64654/AlaskaLauncher/releases/latest).
2. Run it. Windows may show **"Windows protected your PC"** because the installer isn't code-signed yet. Click **More info → Run anyway**.
3. Pick an install folder (no admin needed), finish setup, and sign in.

Requirements: Windows 10 or 11, 64-bit. Java is detected or downloaded automatically.

Uninstall from **Settings → Apps**. Your worlds, accounts and settings are kept.

## Verify your download

Each release lists the installer's SHA-256 checksum. In PowerShell:

```powershell
Get-FileHash .\AlaskaLauncher-Setup-1.0.0.exe -Algorithm SHA256
```
